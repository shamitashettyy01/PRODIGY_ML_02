# Customer Segmentation using K-Means Clustering

## 📌 Overview
This project is a part of my Data Science Internship at Prodigy InfoTech.  
The aim of this project is to implement a K-Means clustering algorithm to group retail store customers based on their purchase history.

---

## 🎯 Objective
To build a customer segmentation model using K-Means clustering.

---

## 📂 Dataset
The dataset contains customer information such as:
- Customer ID
- Annual Income
- Spending Score

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## ⚙️ Steps Performed
1. Imported required libraries  
2. Loaded and analyzed dataset  
3. Selected important features  
4. Applied K-Means clustering  
5. Visualized customer clusters  
6. Evaluated clustering results  

---

## 📊 Model Used
- K-Means Clustering

---

## 📈 Outcome
Successfully grouped customers into different segments based on purchasing behavior.
